Fix the issue: $ARGUMENTS

1. Understand the issue fully before touching any code
2. Find root cause with evidence from actual code — no assumptions
3. State what will change and what will NOT be touched
4. Implement minimal fix only
5. Run tests if they exist
6. Commit: "fix: [clear description of what was fixed]"
